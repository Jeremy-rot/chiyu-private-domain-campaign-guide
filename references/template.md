## 一、月度内容排期表（4321栏目矩阵）

> 栏目配比：干货40% / 生活人设30% / 客户证言20% / 促销种草10%（广告>30%易屏蔽）。
> 固定栏目（干货日/证言日/互动日/会员日）× 变量栏目（节气/热点/活动期）。
> 互动型内容白天推送、促销型内容晚上推送，间隔≥2h。

| 周次 | 日期 | 时段(早8·午12·晚8) | 栏目类型 | 内容主题 | 适用人群 | 触达渠道 | 文案钩子 | 负责人 | 素材就绪状态 | 发布 | 复盘指标 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| W1 | [MM-DD] | [早8] | [干货] | [主题] | [人群] | [社群] | [钩子] | [角色] | [就绪] | [待发] | [打开X%·互动Y·转化Z] |
| ... | | | | | | | | | | | |

**栏目矩阵自检**：
- 干货占比 [ ]% ≥35% ｜ 促销占比 [ ]% ≤15% ｜ 广告合计 [ ]% <30%
- 固定栏目 [ ] 类（干货/证言/互动）≥3 且周覆盖
- 活动期内容（预热/正式/收尾）已嵌入对应日期，与活动方案三段节奏一一对应

## 二、活动方案（6要素 + 3段节奏）

### 活动6要素
- 名称：[活动名]
- 主题&口号：[主题 / 口号，与目标一致·引起共鸣·简洁易记]
- 周期：[预热 D-3~D-1 / 正式 D-day / 收尾 3h]（节日时间【以当年官方公告为准】）
- 目标：[Q5目标，具体可衡量]——三层咬合映射：[互动率 → 复购券核销率 → 业绩指标(GMV/客单/翻台)【待印证·按业务校准】]（缺咬合触发异常6）
- 人群：[存量好友分层、规模；无数据按新加/一般粗分标【粗分】]
- 总预算：[Q8真实金额]

### 玩法概览
[一句话说明核心玩法与核心卖点]

### 三段节奏

**预热（D-3 ~ D-1）**
- 目标：[建信任/放大期待/筛高意向]
- 动作：[痛点种草 D-3 → 价值输出+案例证言 D-2 → 悬念剧透+预告福利 D-1]
- 话术样本：「[行业]里 80% 的人卡在 [痛点]，[D-day] 拆一个解法，群内专属 [利益点]」
- 指标：[7日互动率>40% 蓄水达标线【待印证·按业务校准】]

**正式（D-day）**
- 目标：[集中引爆]
- 动作：[早间开场+价值锚定 → 中段方案讲解+限时福利 → 群内晒单+从众 → 锁单指引]
- 话术样本：「[产品] 今天 [利益点]，仅 [名额] 个，晒单接龙👇 现在锁单额外送 [赠品]」
- 指标：[转化率 / 客单 / 接龙参与数]

**收尾（最后 3h）**
- 目标：[逼单补单]
- 动作：[倒计时 3h/1h/30min → 名额将罄 → 遗漏痛点再戳 → 最后加赠收口]
- 话术样本：「剩最后 [X] 个名额，[利益点] 即将关闭，错过恢复原价」
- 指标：[收尾段转化占比 / 补单率]

### 奖励机制
- 类型：[物质(券/红包/实物) × 社交货币(排行榜) × 身份(进阶群/勋章)]（力度与客单价匹配：客单30→5-10元档；客单100+→半价/免单档）
- 数量与上限：[每用户上限 / 活动总量上限 / 连续奖励规则]
- 发放方式与时效：[自动到账/手动核销、有效期]

### 传播出口
- 一级出口：[朋友圈海报 / 群内分享卡片 / 邀请好友链接]
- 二级出口：[小程序卡 / 视频号直播口播 / 公众号图文嵌入]
- 裂变钩子：[邀X人解锁更高奖]（K≥1 见玩法机制自检）

### 风险合规
- [广告法无极限词 / 无虚构原价 / 无诱导分享（"转发得奖励"→改"参与活动解锁"）]（缺触发异常2）
- [抽奖5条 / UGC审核+肖像授权+未成年人保护]（缺触发异常1/3）
- [防刷四闸齐；裂变K>1.5有熔断预案]（缺触发异常4/8）

### 复盘指标
- [总转化率/客单/ROI/各段流失 + 互动→核销→业绩咬合验证]

## 三、玩法机制

### 玩法选型
- 玩法类型：[任务宝 / 助力砍价 / 拼团 / 分销 / UGC征集 / 打卡签到 / 答题 / 抽奖 / 榜单]
- 选型依据：[低客单→助力拼团｜中客单→任务宝｜高客单→老带新分销｜日常→打卡答题UGC；结合客单价与活动目标]
- 选择理由：[钩子决定参与率，阶梯门槛决定裂变系数]

### 用户路径三要素
- 参与门槛：[如 发图+话题 / 满X元 / 邀1人]
- 任务动作：[触达→参与→行动→兑奖→(分享)]
- 奖励兑现：[领券/抽奖/积分到账 + 上限/时效]
- 传播出口：[朋友圈/群内分享/邀请好友/海报/小程序卡]

### 门槛三阶梯
- 基础档：[低门槛动作] → 解锁 [基础奖励]，拉参与率
- 进阶档：[中门槛动作] → 解锁 [进阶奖励]，拉裂变系数
- 头部档：[高门槛动作] → 解锁 [终极奖励]，拉头部传播者

### 激励组合
[物质(实物/券) × 社交货币(排行榜) × 身份(进阶群/勋章)]

### K系数自检（裂变类玩法必填）
- K = 人均邀请数 [X] × 邀请转化率 [Y] = [K值]
- 判定：[K≥1 可放量 / K<1 不可放量需调激励/门槛/钩子]（禁"高/中/低"模糊词）
- 非裂变玩法（打卡/答题/UGC晒单）：K不适用，改用 [任务完成率/UGC产出率] 作主指标

### 防刷四闸
1. [同设备/IP限制]
2. [奖励延迟兑现（24h 未退群/未退款才发）]
3. [风控阈值+人工抽检]
4. [仅新用户计入邀请数]

## 四、物料清单BOM（10列）

> 每行物料用途必指向方案某节点；预算合计 ≤ 总预算（超触发异常5）。
> 权限分级：对外版（隐藏预算字段）/ 内部版（全字段）。
> 海报四要素自检：主标(利益点) + 副标(门槛) + 行动指令(扫码) + 紧迫感(限时限量)。

| 物料名称 | 规格 | 数量 | 用途(对应方案节点) | 渠道 | 负责人 | 到货·上线时间 | 预算 | 产出方式(设计外包/门店自制/AI生成) | 状态 |
|---|---|---|---|---|---|---|---|---|---|
| [活动主海报] | [750×1334] | [N张] | [预热D-3种草] | [朋友圈+社群] | [设计] | [MM-DD] | [金额] | [AI生成+人工修] | [就绪] |
| ... | | | | | | | | | |

**BOM自检**：
- 预算合计 [金额] ≤ 总预算 [金额]（超→砍项或加预算）
- 关键物料到货时间 ≤ 活动上线时间（晚→提前采购）
- 海报类物料过四要素自检 [ ] 主标 [ ] 副标 [ ] 行动指令 [ ] 紧迫感
- AI 生成物料附要点提示（如：主海报=利益点大字+产品实拍图+扫码区）

> 连锁品牌必出；纯线上品牌降级为「账号矩阵协同排期」（主号+店员号+视频号/公众号）。

### 总部统一动作
- [统一主题/物料包/话术包/内容素材库，D-X前下发门店群]
- [活动数据日报模板：各店参与数/核销数/GMV，每日X点前回报]

### 门店属地执行
- [门店朋友圈+社群转发节奏：与月度排期表日期同步，早8/午12/晚8]
- [店长确认清单：物料到店/店员知晓话术/核销流程演练，D-1前完成]
- [门店侧钩子：到店核销额外福利，线上参与承接到店]

### KOS内容排期（店员/达人）
| 日期 | KOS角色(店长/店员/达人) | 内容形式(短视频/图文/口播) | 内容主题 | 发布渠道 | 钩子 |
|---|---|---|---|---|---|
| [MM-DD] | [店长] | [口播短视频] | [真实感:活动筹备日常] | [视频号+朋友圈] | [预约锁福利] |

- KOS内容三要素：真实感（门店日常/筹备花絮）× 专业感（品类知识）× 福利感（活动利益点）
- 频次：每周[X]条，活动期加密【按团队人力校准；店员每人每周≤3条】

## 自检清单（五件套交付前过）

- [ ] 合规：广告法/诱导分享/抽奖5条/UGC审核+肖像授权+未成年人保护

- [ ] 门店执行三层齐全（纯线上已降级为账号矩阵版）
- [ ] 平台规则项标【按最新规则核验·需复核】、行业基准标【待印证·按业务校准】
