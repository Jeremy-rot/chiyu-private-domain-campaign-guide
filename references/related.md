# 品牌私域高效转化活动方案制定 — 相关技能边界与组合用法

> 厘清本技能与驰誉AI技能族内姊妹技能的边界划分、咬合关系与组合用法，避免用户混用。

「品牌私域高效转化活动方案制定」在驰誉私域方法论（《持续变现私域底层架构》：造IP→做链接→搞促活→做分层→拉复购）中是**「搞促活」环节的建设方**：向上承接「造IP、做链接」沉淀的私域资产，向下为「做分层、拉复购」输送活跃与转化数据。

## 边界划分矩阵

| 维度 | 品牌私域高效转化活动方案制定（本技能） | 实体连锁私域运营方案制定（skill2） |
|---|---|---|
| 回答的问题 | 拿什么内容与活动让私域活跃并接住转化 | 存量用户日常怎么分层触达（对谁/走哪个触点/什么频次） |
| 核心场景 | 会员日、节日大促、沉睡唤醒活动、裂变活动 | 日常1v1/朋友圈/群发/社群触达排期与合规 |
| 产出 | 五件套：月度内容排期+活动方案+玩法机制+物料BOM+门店KOS排期 | 六模块：摸排+触达方式思路+适配文案+推送排期+企微合规校验+衔接动作 |
| 人群框架 | 新加/一般粗分（无数据）或按活动目标分层 | 四类人群包（新加/一般/有价值/高价值） |
| 频次视角 | 活动三段节奏（预热/正式/收尾）+ 月度内容排期 | 企微官方额度内的日常触达频次总控 |
| 独立可用 | 是 | 是 |

## 咬合关系

- **日常触达 ↔ 活动引爆**：skill2 的日常触达排期（四类人群包×触点）是"平时怎么养"，本技能的活动方案是"节点怎么爆"。活动期内容嵌入本技能月度排期表，非活动期日常触达沿用 skill2 方案，两者日期对齐不冲突。
- **活动数据 → 分层弹药**：本技能活动产生的参与/核销/裂变数据按用户打标（高参与=有价值用户、核销=复购用户），沉淀为 skill2 四类人群包的分层依据（「做分层」）。
- **人群包 → 活动投放对象**：skill2 的四类人群包结论可作为本技能活动方案「人群」字段的输入（高价值用户走1v1专属活动邀请，一般用户走社群活动）。
- **独立使用**：两个技能解决不同环节的问题，可分别安装、互不依赖。

## 怎么组合（3 种用法）

1. **完整私域运营链路（先 skill2 → 再本技能）**：先用「实体连锁私域运营方案制定」把存量用户分层与日常触达跑起来 → 日常活跃有基础后，用本技能策划会员日/大促活动引爆转化。适用于私域体系从零搭建。
2. **只做活动（独立用本技能）**：已有日常触达节奏，仅缺活动策划能力 → 直接用本技能产五件套。适用于运营有基础但活动散装的品牌。
3. **活动复盘回填（先本技能 → 回 skill2）**：活动做完沉淀了参与/核销数据 → 回 skill2 重新评估四类人群包分层，调整日常触达方案。适用于活动驱动型品牌。

## 一句话区分用户该用哪个

- 想知道"存量好友平时怎么触达、频次怎么排、怎么不被折叠"→ **实体连锁私域运营方案制定**
- 想知道"会员日/大促/唤醒/裂变活动怎么策划落地"→ **品牌私域高效转化活动方案制定**（本技能）
